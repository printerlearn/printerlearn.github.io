Canon IJ Scan Utility is a scanning application designed for compatible Canon printers and scanners. It can help you scan documents and photos, select scan settings, and save scanned files on your computer.

What Is Canon IJ Scan Utility?

Canon IJ Scan Utility is software that provides scanning functions for compatible Canon printers and scanners. Depending on your Canon model and computer operating system, the software can provide options for scanning documents, photos, and other originals.

You can use the available scan options to choose how an original should be scanned and where the resulting file should be saved.

Canon IJ Scan Utility Setup

Before using IJ Scan Utility, make sure your Canon printer or scanner is properly connected to your computer. The connection can be through USB or, on supported models, through a wireless network.

  1. Turn on your Canon printer or scanner.
  2. Connect the device to your computer using USB or a supported WiFi connection.
  3. Make sure the scanner is detected by the computer.
  4. Install the compatible Canon scanning software for your printer model.
  5. Open IJ Scan Utility.
  6. Select the scan function you want to use.
Tip: Canon software availability and features can vary by printer or scanner model and operating system.

How to Install Canon IJ Scan Utility

The installation process depends on your Canon printer model and operating system. Use the software intended for your specific Canon device and operating system.

  1. Identify your Canon printer or scanner model.
  2. Check the software available for that model.
  3. Download the compatible Canon scanning software.
  4. Open the downloaded installer.
  5. Follow the installation instructions.
  6. Complete the setup process.
  7. Restart the computer if the installer requests it.
  8. Open IJ Scan Utility and check whether the scanner is detected.

How to Use Canon IJ Scan Utility

Once the software is installed and the scanner is connected, you can use IJ Scan Utility to scan documents and photos.

Step 1: Prepare the Original

Place the document or photo on the scanner glass or in the automatic document feeder if your Canon model supports one.

Step 2: Open IJ Scan Utility

Open Canon IJ Scan Utility from your computer's installed applications or programs.

Step 3: Select a Scan Option

Select the scan option that matches the type of original you want to scan. Available options can vary by Canon model and software installation.

Step 4: Adjust Scan Settings

Depending on the available options, you may be able to adjust settings such as document type, scan size, resolution, color mode, and file format.

Step 5: Start the Scan

Start the scan and wait for the scanner to complete the process.

Step 6: Save the Scanned File

After scanning is complete, check the destination folder and confirm that the scanned document or photo has been saved correctly.

Canon IJ Scan Utility for Windows

On Windows, IJ Scan Utility can be used with compatible Canon printers and scanners after the required software has been installed.

If the scanner is not detected, check the USB connection or make sure the Canon printer and Windows computer are connected to the same WiFi network when using a wireless setup.

Windows Troubleshooting Checklist

  • Make sure the Canon printer is turned on.
  • Check the USB cable if using a USB connection.
  • Check the wireless connection if scanning over WiFi.
  • Make sure the scanner is detected by Windows.
  • Restart the printer and computer.
  • Open IJ Scan Utility again after restarting.

Canon IJ Scan Utility for Mac

Compatible Canon scanning software can also provide scanning functions on Mac computers. Make sure the software is compatible with your Canon printer or scanner and macOS version.

If the scanner is not available, check the printer connection and make sure the Mac can communicate with the Canon device.

How to Scan a Document Using Canon IJ Scan Utility

  1. Turn on the Canon printer.
  2. Place the document on the scanner glass or feeder.
  3. Connect the printer to the computer.
  4. Open Canon IJ Scan Utility.
  5. Select the appropriate document scan option.
  6. Choose the available scan settings.
  7. Start scanning.
  8. Check the saved file after the scan finishes.

How to Scan a Photo Using Canon IJ Scan Utility

To scan a photo, place it correctly on the scanner glass and open IJ Scan Utility. Select the appropriate photo or image scanning option if it is available for your Canon model.

Choose the desired scan settings and start the scan. After completion, check the selected save location for the scanned image.

Canon IJ Scan Utility Not Detecting Scanner

If IJ Scan Utility cannot find your Canon scanner, first check the physical or wireless connection.

  • Make sure the Canon printer is powered on.
  • Check the USB cable if using USB.
  • Check the WiFi connection if using wireless scanning.
  • Make sure the computer and printer are on the same network.
  • Restart the printer.
  • Restart the computer.
  • Open IJ Scan Utility again.

If your Canon printer is not scanning at all, visit our Canon Printer Won't Scan troubleshooting guide.

Canon IJ Scan Utility Not Working

If the application opens but scanning does not work, check whether the printer or scanner is correctly connected and detected by the computer.

Also check that the correct Canon software is installed for your printer model and operating system.

Important: Do not install software intended for a different Canon printer model. Check your exact printer model and operating system before installing scanning software.

Canon IJ Scan Utility Cannot Save Scanned Files

If scanning works but the resulting file cannot be saved, check the selected save location and make sure the computer has permission to write files to that folder.

You can also check whether the computer has sufficient storage space and try saving the scan to another folder.

Canon IJ Scan Utility and WiFi Scanning

Compatible Canon wireless printers can allow scanning over a WiFi network. For wireless scanning to work, the printer and computer generally need to communicate through the same local network.

If the Canon printer is not connected to WiFi, first resolve the wireless connection problem before troubleshooting the scanning software.

See our Canon Printer WiFi Setup guide for general wireless setup help.

Canon IJ Scan Utility and USB Connection

If you are using a USB connection, make sure the cable is securely connected to both the Canon printer and computer.

If the scanner is not detected, disconnect and reconnect the USB cable and restart the printer and computer.

Quick Canon IJ Scan Utility Troubleshooting Checklist

  • Canon printer is turned on.
  • Scanner is correctly connected.
  • USB cable is securely connected when using USB.
  • Printer and computer are on the same WiFi network when using wireless scanning.
  • Compatible Canon scanning software is installed.
  • IJ Scan Utility opens correctly.
  • Scanner is detected by the computer.
  • Correct scan option is selected.
  • There is enough storage space for the scanned file.
  • The selected save folder is accessible.

Frequently Asked Questions

What is Canon IJ Scan Utility?

Canon IJ Scan Utility is software for scanning documents and photos using compatible Canon printers and scanners.

How do I open Canon IJ Scan Utility?

After installing the compatible Canon scanning software, open IJ Scan Utility from your computer's installed applications or programs.

How do I scan using Canon IJ Scan Utility?

Place your document or photo on the scanner, open IJ Scan Utility, select the appropriate scan option, adjust the available settings, and start the scan.

Why is Canon IJ Scan Utility not working?

The scanner may not be connected correctly, the computer may not detect the Canon device, or the required Canon scanning software may not be installed correctly.

Can I use Canon IJ Scan Utility over WiFi?

Compatible Canon wireless printers and scanners can support scanning over WiFi when the printer and computer are correctly connected to the same network.

Why is my Canon scanner not detected?

Check the USB or WiFi connection, restart the printer and computer, and make sure the compatible Canon scanning software is installed.

Where are my scanned files saved?

The save location depends on the scan settings and software configuration. Check the destination folder selected in the scanning application.

Conclusion

Canon IJ Scan Utility provides a convenient way to scan documents and photos with compatible Canon printers and scanners. Before scanning, make sure the printer is connected correctly, the required Canon software is installed, and the scanner is detected by your computer.
